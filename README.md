# Automobile Simulator
Create your own Car; set up the engine, drivetrain,
crankshaft and other properties. You can then test this car of yours on the road.
Under development. 

## Current Features
1. Set Engine properties
2. Set Transmission properties 
3. Pygame engine simulation; simplified dyno with tachometer. 

## Under Development
1. Transmission logic.
2. Car Object that assembles the engine and transmission. 

## Future features
1. Expanded pygame simulation interface and telemetry 
2. 'DRIVE MODE' where you can test the vehicle on a straight line road or an actual track.
